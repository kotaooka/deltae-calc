# deltae-calc — 色差累積ビューア

ターゲット → 承認塗板 → 製品 の 3 段で、色差がどう積み上がるかを確認する Web ツールです。
2 段の色差（ΔL\* Δa\* Δb\*）を入れると、ターゲットから見た製品の色差・ずれの向き・許容差に対する余裕を図で示します。

**Web 版**: https://kotaooka.github.io/deltae-calc/

## できること

- 差 1（承認塗板 − ターゲット）と差 2（製品 − 承認塗板）から、ターゲット → 製品の色差を計算
- 色差式の切替：CIE76 / CIE94（塗装・一般、繊維）/ CMC(l:c) / CIEDE2000（kL・kC・kH 可変）
- 測定条件の切替：単一条件（名称は自由入力）/ 5 角度（15°・25°・45°・75°・110°）
- フロップインデックス FI と ΔFI（5 角度、絶対値入力時）
- 3 組それぞれの許容差判定、角度別の棒グラフ、a\*b\* 平面での位置と許容範囲、L\* の比較
- 累積の比較（単純加算・二乗和平方根・実際の値）と、ずれの向き（積み上がり／打ち消し）の判定
- 許容差の配分チェック（承認塗板の許容差 ＋ 対承認塗板の許容差 ＞ 対ターゲットの許容差 のとき警告）
- Excel からの範囲貼り付け、結果の TSV コピー、入力値のブラウザ保存

## 絶対値の入力について

| 入力 | 計算できるもの |
|---|---|
| 差 1・差 2 のみ | CIE76、a\*b\* の相対位置、ずれの向き |
| ＋ターゲットまたは承認塗板の絶対値 L\*a\*b\* | 上記に加えて CIE94・CMC・CIEDE2000、FI・ΔFI、色見本 |

CIE94・CMC・CIEDE2000 と FI は基準色そのものの L\*・C\*・h で重みが変わるため、差だけでは計算できません。

## 計算式と検証

- CIEDE2000：CIE 142-2001。Sharma らの公式テストデータ 34 組と一致（基準・試料の入替も含む）
- CIE94・CMC(l:c)・CIEDE2000：colour-science 0.4.7 の実装と 300 組で照合し、差は 1×10⁻¹³ 未満
- FI = 2.69 (L\*15° − L\*110°)^1.11 / L\*45°^0.86（X-Rite MA シリーズの定義）
- 差の向きは「試料 − 基準」。CIE94 と CMC は基準側の値で重みが決まるため、向きを入れ替えると値が変わります
