# 色差累積ビューア（deltae-calc）

色見本（ターゲット）→ 承認塗板 → 製品 と色を引き継いでいくと、それぞれの段で生じた小さな色のずれが積み重なり、製品とターゲットの色差が大きくなることがあります。
このツールは、測色計の値を入れるだけで「製品はターゲットからどれだけずれているか」「ずれが積み上がっているのか、打ち消し合っているのか」「許容差まであとどれくらい余裕があるか」を図で示します。

**今すぐ使う → https://kotaooka.github.io/deltae-calc/**

- ブラウザだけで動きます。インストールやユーザー登録は不要です
- 入力した数値はお使いの端末の中だけで計算し、外部には送信しません
- スマホ・タブレット・PC のどれでも使えます

## 使い方

![画面全体](docs/screenshots/overview.png)

1. **計算条件を選ぶ**：色差式、測定条件（単一条件か 5 角度か）、手元にあるデータの形を選びます
2. **測定値を入れる**：測色計の値を入力します。Excel の表をコピーして、左上のセルに貼り付けることもできます
3. **許容差を入れる**：3 つの組み合わせ（ターゲット → 承認塗板、承認塗板 → 製品、ターゲット → 製品）それぞれの許容差を入れます
4. **結果を見る**：入力するとすぐ、判定とグラフが更新されます

### 計算条件

![計算条件](docs/screenshots/conditions.png)

| 項目 | 選べるもの |
|---|---|
| 色差式 | CIE76（ΔE\*ab）／ CIE94 ／ CMC(l:c) ／ CIEDE2000（ΔE00）。取引先の規格で指定された式を選んでください |
| 測定条件 | **単一条件**：SCI・SCE など 1 つの条件で測った値（名称は自由に変えられます）<br>**5 角度**：メタリック・パール塗装用の多角度測色計の値（15°・25°・45°・75°・110°） |
| 手元のデータ | 持っている測定値の形に合わせて選びます（次の表） |

### 手元のデータに合わせた入力

測色計から「差（ΔL\* Δa\* Δb\*）」だけを控えている場合も、各試料の値（L\* a\* b\*）を控えている場合も使えます。

| 選択 | 入力するもの | できること |
|---|---|---|
| 差のみ | 承認塗板 − ターゲット、製品 − 承認塗板 の ΔL\* Δa\* Δb\* | CIE76 での判定、ずれの向き |
| 差＋ターゲット<br>差＋承認塗板 | 上の 2 つの差と、どちらか 1 つの L\* a\* b\* | すべての色差式、フロップインデックス、色見本 |
| 3 試料の絶対値 | ターゲット・承認塗板・製品それぞれの L\* a\* b\* | すべての色差式、フロップインデックス、色見本（差は自動で計算） |

「差のみ」で CIE76 しか選べないのは、CIE94・CMC・CIEDE2000 が「元の色が鮮やかか、明るいか」で重みを変える式で、差だけでは計算できないためです。

<p><img src="docs/screenshots/input-diff.png" width="48%" alt="差＋ターゲットの入力"> <img src="docs/screenshots/input-abs.png" width="48%" alt="3 試料の絶対値の入力"></p>

左：差＋ターゲット、右：3 試料の絶対値。途中で選択を切り替えても、入力済みの値は同じ色を表すように換算して引き継ぎます（「差のみ」から切り替えたときは、絶対値を入れ直してください）。

## 結果の見方

### 判定

![判定](docs/screenshots/judge.png)

- 一番上に **合格 / NG** と、NG になった組み合わせ・角度を表示します
- 3 枚のカードは、組み合わせごとの色差です。5 角度のときは、許容差に対して最も厳しい角度の値を大きく表示し、下に全角度の値を並べます
- 許容差の 80 % を超えると「余裕小」と表示します

### 角度別の色差とフロップインデックス（5 角度のとき）

![角度別の色差とフロップインデックス](docs/screenshots/angles.png)

- **角度別の色差**：角度ごとに 3 つの組み合わせの色差を並べます。黒い破線が許容差です。棒をクリックすると、下の「詳細」がその角度に切り替わります
- **フロップインデックス（FI）**：見る角度によって明るさがどれだけ変わるか（メタリック感の強さ）を表す値です。ソリッド塗装は 0、メタリック・パールは 10〜17 程度になります。ΔFI がプラスなら、試料の方がメタリック感が強いことを表します

### 詳細

![詳細](docs/screenshots/detail.png)

- **色見本**：入力した値を画面の色で再現した目安です（メタリック感は再現できません）
- **色の地図（a\*b\* 平面）**：右に行くほど赤み、上に行くほど黄みが強い色です。矢印は色が引き継がれた順番で、破線の囲みが許容範囲です。製品の点が桃色の囲みの外に出ると、ターゲットに対して NG です
- **明るさ（L\*）**：右の縦棒で、3 つの試料の明るさを比べます
- **色差の積み上がり**：2 段の色差を足した値（最悪の場合）と実際の色差を比べ、ずれが「積み上がっている」「打ち消し合っている」かを文章で示します
- **許容差の配分**：承認塗板の許容差と、製品（対承認塗板）の許容差の合計が、製品（対ターゲット）の許容差を超えていると警告します。この場合、どちらの段も合格なのに最終的に NG になることがあります
- **何がずれているか**：明るさ・鮮やかさ・色合いのどれが色差の原因かを棒グラフと言葉（「やや暗い」「わずかに黄み寄り」など）で示します

## アプリとして入れる（オフラインでも使えます）

ホーム画面やデスクトップに追加すると、アプリのように起動でき、一度開いたあとは通信がなくても使えます。

| 端末 | やり方 |
|---|---|
| Android（Chrome） | メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」 |
| iPhone・iPad（Safari） | 共有ボタン →「ホーム画面に追加」 |
| Windows・Mac（Chrome / Edge） | アドレスバー右端のインストールボタン |

新しい版が公開されると、次に開いたときに自動で取り込みます。画面に「開き直すと反映されます」と出たら、一度閉じて開き直してください。

## 便利な使い方

- **Excel から貼り付け**：Excel で範囲を選んでコピーし、入力表の左上のセルに貼り付けると、まとめて入ります。並びは画面の表と同じ（角度が行、L\* a\* b\* が列）です
- **結果を Excel へ**：「結果を TSV でコピー」を押すと、全角度・全組み合わせの結果をコピーします。Excel にそのまま貼り付けられます
- **入力は自動で保存**：入力した値はブラウザに保存され、次に開いたときも残っています。サンプル値に戻すときは「サンプル値に戻す」を押してください

## 使うときの注意

- **差の向き**：差は「試料 − 基準」（承認塗板 − ターゲット、製品 − 承認塗板）で入れてください。多くの測色計の表示と同じ向きです。逆向きで入れると、「積み上がり」と「打ち消し」の判定が逆になります
- **測定条件をそろえる**：3 試料の絶対値を使うときは、同じ測色計・光源・視野で測った値を使ってください。ターゲットだけ色見本の成績書の値（別の機器で測った値）を使うと、機器の差がそのまま色差に含まれます
- **色差式は混ぜない**：同じ数値でも、式が違えば色差は大きく変わります（CIEDE2000 の 1.0 と CIE76 の 1.0 は別物です）。許容差を決めたときと同じ式で判定してください
- **画面の色見本は目安**：モニターの設定によって見え方が変わります。目視の判定には実物を使ってください
